# LinkedIn / GitHub Project Summary

SecureDox is a senior SDET and DevSecOps portfolio project built around a
regulated document-intake workflow.

It includes a working web/API/worker app, mocked OCR, document review, audit
events, API/DB/E2E/security/OCR/contract tests, release-readiness gates,
security scanning, SBOMs, Prometheus/Grafana observability, SRE runbooks,
Terraform, Ansible, Kubernetes manifests, and a local MCP Test Architect for
AI-assisted test design.

The project is meant to show how I think about real release risk: what changed,
what can break, what evidence proves it, and what blocks a release.
