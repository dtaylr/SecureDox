# Resume Bullets

- Built SecureDox, a regulated document-intake platform with FastAPI, React,
  async worker processing, Postgres, Redis, Docker Compose, Nginx, and an
  append-only audit trail.
- Designed a risk-based SDET framework covering API, DB integrity, Playwright
  E2E, security, OCR validation, contract, observability, and architecture
  policy tests.
- Implemented release-readiness gates that combine test, security, SBOM,
  container, reliability, audit, and AI-generated-test review evidence into a
  single GO/NO-GO decision.
- Added DevSecOps controls with pre-commit, Gitleaks, Semgrep, Trivy, SBOM
  generation, Hadolint, container scanning, and CI security workflows.
- Built SRE foundations with structured logs, correlation IDs, Prometheus
  metrics, Grafana dashboards, alert rules, and runbooks with failure-injection
  drills.
- Created a local MCP Test Architect and agent helper system that detects
  changed routes, API contracts, DB schema, and security-sensitive files, then
  recommends impacted tests and release gates.
- Added platform assets across Terraform, Ansible, Kubernetes/minikube, Nginx,
  Docker Compose hardening, IaC scans, and architecture tests.
